# ACL Scan

Docker Space for the ACL tear detection demo site.

This repository contains:

- `backend.py`: Flask API and model inference
- `acl_scan.html`: frontend
- `best_model.pth`: trained checkpoint

## Run

The app starts automatically in Hugging Face Spaces on port `7860`.
